MongoDB Quick Essentials
1. Basic CRUD Operations
Operation	Method	Example
Create	insertOne() / insertMany()	db.users.insertOne({name: "Ali", age: 25})
Read	find() / findOne()	db.users.find({age: {$gte: 20}})
Update	updateOne() / updateMany()	db.users.updateOne({name: "Ali"}, {$set: {age: 26}})
Delete	deleteOne() / deleteMany()	db.users.deleteMany({age: {$lt: 18}})

2. Query Operators
Comparison: $eq, $gt, $gte, $lt, $lte, $ne, $in, $nin
Logical: $and, $or, $not, $nor
Element: $exists, $type
Evaluation: $regex (regular expressions)
Array: $all, $elemMatch, $size, $push, $pull

3. Projection
Controls which fields are returned. Use 1 to include, 0 to exclude (except _id can be excluded).
Important: Can't mix inclusion and exclusion (except _id).
Example:
db.products.find({}, { name: 1, price: 1, _id: 0 })

4. Update Operators
$set, $unset, $inc, $push, $pull, $addToSet

5. Aggregation
Pipeline stages like $match, $group, $sort, $project, $limit, $lookup
$group must have _id field specifying the group key

6. Indexes
Improve query speed
Created via db.collection.createIndex({field: 1}) for ascending

7. MongoDB Atlas Basics
Cloud-hosted MongoDB with UI and automation
Connect with a connection string (mongodb+srv://...)
Use MongoDB Compass or your code driver to connect
Set IP whitelist to allow your client access
Manage users and roles for security
Can create clusters (free/shared or paid)
Supports backups, monitoring, and alerts

8. Common Pitfalls
Mixing data types in queries (string vs number)
Wrong projection syntax
Forgetting to wrap update operators in {}
Missing _id in $group stage in aggregation
Not handling async properly when using drivers
